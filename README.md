# 応援管理・請求書

型枠工事の「応援」に行った日程と内容を記録し、月末（締め日）にまとめて請求書を作るためのシンプルなWebアプリです。
インストール不要で、`index.html` をブラウザで開くだけで使えます（スマホ・PC 両対応）。

## できること

- **記録入力**：「応援に行った（請求する）」と「応援に来てもらった（支払う）」を切り替えて記録。日付・取引先・現場名・作業内容・人数（人工、0.5単位）・単価・残業・経費（交通費・駐車場など）・作業員名・備考
  - 応援先を選ぶと標準単価が自動で入ります
  - 「最近の記録」から「コピー」で、同じ内容を翌日分としてすぐ入力できます
- **一覧**：月・種類・取引先で絞り込み、行った分（請求）と来てもらった分（支払）を分けて集計、差し引きも表示。CSV出力（Excel で開けます）
- **請求書**：請求月と請求先を選ぶと、締め日（末日／5・10・15・20・25日）に合わせた期間の記録から請求書を自動作成
  - 人工・残業・経費を明細行に分けて表示、消費税（税率・端数処理は設定可）を計算
  - 適格請求書（インボイス）登録番号・振込先・支払条件を記載
  - 「印刷 / PDF保存」で A4 の請求書を印刷、または PDF として保存
  - 「請求済みにする」で記録に請求番号を付け、一覧に「請求済」と表示
- **支払**：来てもらった分を締め日ごとにまとめて、支払金額を確認。支払明細書として印刷・PDF保存、「支払済」の管理
- **設定**：自社情報、応援先（取引先）の登録・編集、データのバックアップ／復元
- **スマホとパソコンの連携**：Googleスプレッドシートにデータを保存し、どの端末でも同じデータを使えます
  - 電波がない所で入力しても、つながった時に自動で送ります（画面上部に「同期済み」「未送信 ○件」と表示）
  - スプレッドシートの「記録」「応援先」「自社情報」シートで中身を直接見られます

## 使い方

1. 「設定」で自社情報と応援先（会社名・締め日・標準単価など）を登録
2. 応援に行った日に「記録入力」で記録
3. 月末に「請求書」で請求月・請求先を選び、内容を確認して「印刷 / PDF保存」

## データについて

データは各端末のブラウザ内に保存されます。Googleスプレッドシートと連携すると、スプレッドシート（自分の Google ドライブ）にも保存され、どの端末でも同じデータになります。GitHub やその他のサーバーには送信されません。
念のため、「設定」→「バックアップを保存」で時々控えを取ってください。

## Googleスプレッドシートとの連携

最初に1回だけ準備が必要です（パソコンでの作業がおすすめ）。手順はアプリの「設定」→「準備のしかた」にも書いてあります。

1. Googleスプレッドシートを新しく作る
2. 「拡張機能」→「Apps Script」を開き、中身を全部消して [`gas/Code.gs`](gas/Code.gs) を貼り付ける
3. `ここを合言葉に変更` を自分で決めた合言葉に書き換えて保存
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行ユーザー「自分」、アクセス「全員」でデプロイし、アクセスを承認
5. 表示された URL（`/exec` で終わる）と合言葉を、アプリの「設定」に入れて「接続する」（スマホ・パソコンそれぞれで）

すでに端末に入力済みのデータは、初めて接続した時にスプレッドシートへ送られます。

## スマホで使うには（GitHub Pages）

1. GitHub のリポジトリ画面で **Settings → Pages** を開く
2. 「Build and deployment」の Source を **Deploy from a branch** にし、Branch で公開するブランチと `/ (root)` を選んで **Save**
3. 1〜2分後、同じ画面に表示される URL（`https://<ユーザー名>.github.io/ouen/`）をスマホで開く
4. ホーム画面に追加すると、アプリのように起動できます（一度開けば電波がない現場でも起動できます）
   - iPhone（Safari）：共有ボタン →「ホーム画面に追加」
   - Android（Chrome）：右上のメニュー →「ホーム画面に追加」

※ 無料プランでは、GitHub Pages は公開（Public）リポジトリでしか使えません。公開されるのはアプリのプログラムだけで、入力した記録や請求データは各端末の中に保存され、GitHub には送られません。
